# Objection Maps Card

## Response Flow

1. acknowledge
2. clarify
3. reframe
4. guide
5. hold boundary

## Fast Counterweights

- "Let’s check the facts step by step."
- "Let’s gather the evidence that matches the issue."
- "I can help prepare this for the right team."
- "No system can eliminate that entirely, but we can reduce it significantly."

## Never Say

- "Don’t worry, we’ll fix everything."
- "We guarantee approval."
- "This is definitely their fault."
