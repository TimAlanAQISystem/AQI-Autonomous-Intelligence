# PCI Card

## Use When

- merchant asks what PCI is
- merchant asks which SAQ applies
- merchant wants to reduce compliance burden

## Core Rule

The less card data the merchant touches, the easier PCI becomes.

## Fast SAQ Guide

- `SAQ A`: fully hosted checkout, no card-data touch
- `SAQ A-EP`: site influences checkout, card data still off merchant systems
- `SAQ B`: simple standalone terminal use
- `SAQ D`: custom or direct card-data environment

## Scope Reduction

- hosted payment pages
- tokenization
- hosted fields
- no card storage
- no custom checkout unless necessary

## Never Say

- "You don’t need PCI."
- "Our processor makes you compliant."
- "We guarantee PCI compliance."

## Safe Phrasing

- "We can help reduce your PCI scope."
- "We can help you identify the correct SAQ."
