# Fraud Card

## Fraud Types

- true fraud
- friendly fraud
- merchant-error fraud

## Core Tools

- AVS
- CVV
- 3-D Secure
- velocity checks
- IP geolocation
- device fingerprinting
- BIN intelligence

## Fast Operator Frame

"Fraud can come from stolen cards, customer confusion, or billing mistakes."

## Red Flags

- mismatched IP and billing country
- repeated attempts from same device
- high-risk MCC
- sudden volume spikes
- digital goods with no proof of delivery

## Never Say

- "We can eliminate fraud."
- "We can guarantee no chargebacks."
